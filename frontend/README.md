# Frontend Documentation — Suchit Vanapilli Portfolio

React 19 + Vite 8 single-page application built with Tailwind CSS v4 and Framer Motion.

## 📁 Source Structure
- `src/components/`: Reusable UI section components (Hero, About, Projects, Contact, Footer, etc.).
- `src/data/`: Data models for projects, skills, education, and certifications.
- `src/hooks/`: Custom React hooks (`useTheme.js`).
- `src/styles/`: Global stylesheets (`index.css`, `App.css`).
- `public/`: Static media assets, icons, and PDF resume documents.

## 🏃 Local Commands
```bash
# Run standalone frontend dev server
npm run dev

# Build production bundle into dist/
npm run build
```
